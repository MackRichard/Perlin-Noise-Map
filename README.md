A Perlin Noise Map is a visual representation of computer-generated, smooth pseudo-random noise.

  - Shows window with a randomly created Perlin Noise Map
  - Colors and pattern are being chosen randomly every time

## 🛠️ Prerequisites

Ensure you have **Python 3.x** installed on your system.

Required library:
- `numpy`
- `matplotlib.pyplot`
- `matplotlib.animation`
- `perlin_noise`
